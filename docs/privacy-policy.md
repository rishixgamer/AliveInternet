# AliveInternet alpha privacy policy

Last updated: October 31, 2026. Applies to the browser extension, version 0.3.

AliveInternet reads rendered posts, comments, public profile links and content links on enabled supported browser pages. It processes them in browser memory to explain or reversibly hide content. The extension does not send this content to us or other servers, collect telemetry, or keep a browsing-history database. It does not access private messages, passwords, authentication cookies or session tokens.

Your preferences, personal mute words, allowlisted profiles and explicit local account hides stay in the browser's local extension storage. A public-indicator pack is also stored locally if you import one. Pack provenance is self-declared; the extension does not fetch its sources. Browser profile storage is not encrypted by AliveInternet. Other people or software with access to your browser profile may read these preferences.

Hidden-item review excerpts exist only in page and popup memory. They are not saved. Settings export creates a local JSON download that may include sensitive profile preferences. Anyone you choose to share that file with can read it; AliveInternet does not upload it.

Optional problem reports. If you press “Wrongly hidden” (on a hidden item or in the popup list) or, after you turn it on in the popup, “Report a miss”, AliveInternet builds a draft in memory and shows it in the popup for you to edit or delete. A draft contains only the site name, the item's text with usernames, display names, @mentions, email addresses, phone numbers and page addresses removed and every link reduced to its hostname (at most 1,000 characters), for hidden items the on-screen reason, your filtering strength, and the extension version. Nothing is sent unless you click “Open GitHub issue draft”. The extension then opens a new browser tab at github.com/rishixgamer/AliveInternet/issues/new with the draft in the address, and you must still submit the issue yourself. The extension makes no request of its own, has no server of ours and does not store drafts; a draft is discarded when you cancel, after it is opened, when you navigate or when the popup closes. GitHub receives the address when the tab opens, and a submitted issue is public under your GitHub account and governed by GitHub's terms and privacy statement. Redaction is automatic but not perfect, and a quoted comment can still lead others to its author, so review the text and do not submit anything you would not post publicly.

Use the popup to change preferences, unhide accounts, clear personal lists, remove an advisory pack, or disable filtering. Disabling a site stops its filtering; disabling an optional site also removes its optional browser grants. Stored preferences remain until changed or the extension is removed. Uninstalling removes the extension's local storage; exported backup files remain where you saved them and must be deleted separately if no longer wanted.

AliveInternet does not sell, share or transfer extension user data, other than text you choose to open in a GitHub issue draft as described above. Its use of website content is limited to the local filtering and review features described above. It follows the Chrome Web Store User Data Policy's Limited Use restrictions. Normal websites and their own requests remain governed by their own privacy policies.

The browser's extension manager controls required YouTube access and optional site access. Nine additional adapters are experimental and receive access only when enabled with browser consent. No imported settings file grants browser permission.
