# Optional anonymous live YouTube smoke

Run `npm run build && npm run test:live` explicitly to check one public watch page with the production extension in a new anonymous Chromium profile. Install Chromium with `npx playwright install chromium` first. The fixed page is the public “Me at the zoo” watch URL; this is an ordinary browser visit with up to eight bounded scrolls, not direct API access or a dataset collection.

The smoke records aggregate counts of modern/legacy comment selectors, rendered extension controls and elapsed time. It opens one visible replies button through normal browser interaction and checks reply-owned profile/control matching in memory. Only checked/mismatched/unknown counts are retained. It does not click a real account-hide button or populate relationship fields. It first disables heuristic filtering, checks that site disabling restores extension UI, and adds a removable minimal synthetic legacy comment node in a neutral container on the live page to exercise its own reversible local account-hide/reveal control. Comment/post rule filtering stays disabled throughout the smoke. All original platform content remains unchanged. No original live text or account identity enters extension preferences, logs or artifacts. Only a synthetic phrase is saved as an inert mute preference and only the synthetic account is locally hidden; no real-content hide is requested. It clears preferences and removes its temporary browser profile on every outcome. It does not sign in, post, vote, change platform accounts or moderation, visit author profiles, save comments/identities, take screenshots, dump DOM, or keep website cache. Normal page resources are loaded by the anonymous browser; the extension still performs no automatic server requests.

Each run saves `artifacts/live-youtube/<timestamp>/receipt.json` with production build hashes and aggregate evidence only. A pass covers that page, Chromium version, observed selector/control matching and a synthetic action on the live page on that date. It does not validate real-content hiding precision. It does not establish classification accuracy, full YouTube coverage, other platforms or other browsers. Missing replies produce a blocked scope result; control/profile mismatches fail the smoke. Missing comments, consent/access restrictions, unavailable page content or browser prerequisites produce `blocked` (exit 2); failed reversible assertions produce `failed` (exit 1). A successful smoke exits 0. Never treat a blocked receipt as live validation.

Optional overrides are `ALIVEINTERNET_EXTENSION_DIR`, `ALIVEINTERNET_LIVE_ARTIFACTS`, `ALIVEINTERNET_PLAYWRIGHT_MODULE`, `ALIVEINTERNET_BROWSER_PATH` and `ALIVEINTERNET_BROWSER_HEADED=1`. Browser launching and live network access may require execution approval in restricted environments. The smoke is separate from offline `test:browser`; it is never run automatically by the extension or the default test suite.

The synthetic action uses a freshly constructed `ytd-comment-renderer` with only a synthetic author anchor and text node. Its native extension button is invoked programmatically because live site CSS may hide synthetic legacy components; this tests the actual handler and resulting reversible UI/storage, not pointer hit-testing on that artificial node. It copies no live markup. Earlier custom-element clone attempts were reset by YouTube hydration and remain failed receipts; those attempts never establish a successful reversible-action claim. The modern comment selector/control count is recorded before adding the synthetic legacy node.
