# Scam pattern of the week

Feature `scam-pattern-changelog`. A public, plain-language log of scam patterns AliveInternet learned to catch, generated from rule-list changes. Doubles as short-form content: show the pattern (blurred), then show it disappearing.

- One file per entry: `YYYY-MM-DD-short-name.md`, from `TEMPLATE.md`.
- Link the rule ids and the PR that added them.
- **Blur or rewrite every username, avatar, phone number and link** in examples and screenshots.
- Describe the *behavior*, never a group of people, nationality or language as the "source".
