# Security policy

AliveInternet runs inside the browser on every enabled social site, so security reports are taken seriously.

**Please do not open public issues for vulnerabilities.** Use [GitHub's private vulnerability reporting](https://github.com/rishixgamer/AliveInternet/security/advisories/new). The repository is public and private reporting is enabled. For privacy questions, use [rishihaldar@umass.edu](mailto:rishihaldar@umass.edu); avoid including private browsing content or exported preferences unless needed to explain the issue.

In scope: the extension (content scripts, popup, storage handling), indicator-pack and rule-list parsing, and the CLI scripts. Especially: anything that lets page content or an imported file execute code, exfiltrate data, or hide content the user did not choose to hide.

There is no hosted backend.
